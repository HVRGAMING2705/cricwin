🏏 CricWin — Cricket Win Probability Predictor

A 2nd-year B.Tech AI/ML project by Vikranth Reddy. A logistic regression model trained on 1,000 synthetic T20 chase states predicts the batting side's chance of winning from the match state: target, runs scored, wickets lost and balls remaining. The required run rate and current run rate are worked out from those four numbers. 5-fold CV: accuracy = 83.0%, AUC = 0.91 vs a majority-class baseline of 56.3%.

How it works: the required run rate (runs needed ÷ overs left) and current run rate (runs scored ÷ overs bowled) are computed from your inputs; all six numbers are standardised (subtract the training mean, divide by the standard deviation), multiplied by the model's learned weights, and summed with a bias; a sigmoid turns the total into a win probability. The exact same weights run in this page and in the Python training script (train.py), so the browser result matches the trained model.

Try it: chasing 180, at 150/3 with 30 balls left → about 91.3% win chance. Chasing 180, at 90/7 with 60 balls left → about 13.1%. Chasing 160, at 110/4 with 36 balls left → about 48.0% — a genuine coin-flip.

Honest note: this model was trained on synthetic chase states generated from simple cricket logic, so it is a classroom demo — real matches have pitch, weather, players and pressure that no six numbers capture.
